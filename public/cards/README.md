# Fondos de las cartas

Los tres fondos ya están acá:

- `gold.png`
- `silver.png`
- `bronze.png`

Si el nombre o las posiciones no quedan bien alineados con el diseño, se ajusta en
**`src/config/cardLayout.ts`**: todas las coordenadas están en porcentajes de la carta,
y cambiar esos números es lo único que hace falta.
